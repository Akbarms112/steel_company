# Bagavan Steels | Quality Steel & Roofing Solutions

Official web application for **Bagavan Steels**, a premier supplier of quality steel, Jindal Trapezoidal PPGL roofing sheets, TMT reinforcement bars, and MS structural steel located in Dharmapuri, Tamil Nadu.

Built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**.

---

## 🌟 Features

- **Interactive Product Catalog**: Comprehensive showcase of Jindal PPGL colour-coated roofing sheets, TMT bars (Fe 500/550D), MS structural steel, pipes, and roofing accessories.
- **Instant Quotation & WhatsApp Integration**: Direct WhatsApp chat triggers allowing customers and contractors to easily request quotes.
- **Client & Customer Segments**: Dedicated views for homeowners, civil contractors, commercial builders, and fabricators.
- **Gallery Showcase**: Visual display of authentic warehouse stock, roofing profiles, structural beams, and inventory.
- **Animated Navigation & Transitions**: Fluid tab switching powered by Framer Motion and 3D card tilt effects.
- **Verified Business Details**: Includes GSTIN, verified dealer badges, direct phone/mobile contacts, and branch/location information.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile viewing.

## 🚀 Getting Started

### Prerequisites

Ensure [Node.js](https://nodejs.org/) (v18 or higher recommended) is installed on your machine.

### Installation

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Akbarms112/steel_company.git
   cd steel_company
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Run the local development server:
```bash
npm run dev
```

The site will run locally at:
```
http://localhost:5173/steel_company/
```

### Production Build

Build the project for production:
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### Preview Production Build

Preview the production build locally:
```bash
npm run preview
```
